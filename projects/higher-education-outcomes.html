My contribution

Prepared institution-level College Scorecard data, assessed missingness, estimated completion and earnings regressions, compared samples with and without admission rate, applied 10-fold cross-validated Lasso, and performed standardized PCA. Extended the project with a Python-to-SQLite audit and an Excel report for sample-count checks, institution-type summaries, and missingness review.

SQL validation & sample checks

The extension audits 14 selected fields from 6,273 College Scorecard records. Python normalizes suppressed and non-numeric values, loads an in-memory SQLite database, and exports identifiers, sample-membership flags, missingness, and institution-type summaries.

Evidence scope: the exact ID matches are recorded results from my local comparison. The repository includes the comparison script, while the four R ID exports and generated reconciliation CSV have not yet been committed. Sample membership does not establish equality of model coefficients or predictive performance.

Repeatable checks

The audit derives QA totals from the data rather than hard-coding them. Two synthetic-data tests cover numeric conversion and basic sample selection. A separate comparison script validates identifiers and inclusion flags, writes a reconciliation CSV, and returns a failure if any R and SQL sample differs.

Excel reporting

I used Python and openpyxl to generate a workbook from the SQL audit exports. The committed file contains four worksheets, eight comparison formulas, and one embedded institution-type bar chart.

The workbook structure, formula expressions, chart object, and stored QA totals were inspected in the committed file. This confirms what the file contains; a fresh desktop Excel recalculation and full visual review remain separate checks.

The report is a saved snapshot. To refresh it, rerun the SQL audit and regenerate the workbook. Its R reference counts and verification note require review after a source change; workbook generation does not run the R-to-SQL ID comparison.

Findings and evidence

Cost of attendance was positively associated with completion and earnings; Pell Grant participation was negatively associated with both, conditional on the other included predictors. Completion R² was 0.4834 and earnings R² was 0.5053. These describe in-sample fit, not held-out prediction.

Adjusted completion R² was 0.4815 with admission rate and 0.4082 without it. Lasso retained all predictor terms at the minimum-error penalty. In PCA, PC1 contrasted cost with admission rates and Pell participation; PC2 was dominated by enrollment. Institution types overlap in the plot.

The question

How do cost, financial aid, selectivity, enrollment, and institution type relate to college completion and earnings?

Data and sample

The audited source snapshot contains 6,273 institution records. Suppressed and non-numeric entries were treated as missing. Complete-case counts vary: 1,618 for the completion model, 2,138 for the model excluding admission rate, 1,949 for earnings, and 1,727 for PCA. The saved SQL missingness output reports admission rate missing for 69.55% of the source.

Interpretation and next steps

These are institution-level associations, not causal effects or estimates for individual students. Missing data limit generalization. R-to-SQL membership matches have been recorded; the remaining reproducibility step is to preserve the independent R ID exports and generated comparison result. A full desktop Excel review and a Random Forest comparison on a common sample and evaluation procedure remain planned.

Statistical results are documented in Weekly Updates #5 and #6. Validation documentation and the committed Excel report were reviewed on October 23, 2026. The source repository remains private; selected methods and aggregate results are summarized here.

Analysis workflow

View the three steps
  1. Analyze in R Clean selected fields and examine completion and earnings with regression, Lasso, and PCA.
  2. Audit in SQL Use Python to load selected fields into SQLite, check identifiers, and export sample-membership flags and summaries.
  3. Report in Excel Use Python and openpyxl to generate a four-sheet report with comparison formulas, QA totals, summaries, and an institution-type chart.
